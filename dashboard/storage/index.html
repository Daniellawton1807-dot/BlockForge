Use this only if a drive has disappeared and normal recovery has failed. The server and hosted services will be unavailable while it restarts.

Restart control requires a secure server-side restart agent.

Important distinction

Glances can show mounted filesystems and may expose disk I/O counters, but it does not reliably report physical-drive SMART health or detect every disconnected disk. A drive missing from this list is not proof of a failed drive. Full hardware health needs a server-side SMART/USB inventory agent.

HOMEBASE• Storage Restart is disabled until an authenticated server-side agent is configured.
