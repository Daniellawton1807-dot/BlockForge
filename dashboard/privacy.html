Jarvis privacy

Last updated 5 November 2026

Jarvis is a personal assistant that runs on one private home server and is used only by its owner. It isn't offered to anyone else.

Google Calendar

With the owner's permission, Jarvis reads and adds events on the owner's own Google Calendar so it can answer questions such as "what's on tomorrow?" and add events when asked. Calendar data is used only to answer those requests. It isn't sold, shared with anyone, or used for advertising.

Jarvis keeps the sign-in token on the home server, in a file only the owner can read. Event details may be passed to the AI model that turns the owner's spoken request into an answer, and are not stored afterwards.

Access can be removed at any time from the owner's Google Account, under Security, then Third-party connections.
